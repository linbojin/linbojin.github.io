Privacy Policy

This policy applies to the openclaw Personal Google Workspace Integration, a private command-line setup used only by its owner.

Google data accessed

Depending on the OAuth permissions granted by the owner, the integration may access Gmail, Calendar, Drive, Docs, Sheets, Slides, Contacts, Tasks, Forms, Apps Script, profile information, and related Google Workspace resources.

How data is used

Google user data is used solely to perform actions explicitly requested by the account owner through the local gog CLI workflow. It is not used for advertising, profiling, or unrelated purposes.

Storage and security

  • The integration runs locally on the owner's Mac.
  • OAuth credentials are stored by gog CLI using the operating system's protected credential storage.
  • This static website does not receive or store Google user data.
  • No Google user data is sold, rented, or shared with data brokers or advertisers.

Limited Use

The integration's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data remains in the owner's Google account or local files created at the owner's request. The owner can delete those files, revoke OAuth access from Google Account settings, or remove the local gog authorization at any time.

Contact

Questions about this personal integration can be raised through the owner's GitHub profile.
