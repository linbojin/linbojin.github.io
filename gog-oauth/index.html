openclaw Personal Google Workspace Integration

This is a private, personal command-line integration that uses gog CLI to let its owner work with authorized Google Workspace data.

What it does

  • Reads and manages Google Workspace resources only after the owner grants OAuth consent.
  • Supports personal workflows involving Gmail, Calendar, Drive, Docs, Sheets, Slides, Contacts, Tasks, Forms, and Apps Script.
  • Runs locally on the owner's Mac and is not offered as a public multi-user service.

Data use

Google user data is used only to perform actions explicitly requested by the account owner. The integration does not sell Google user data or use it for advertising.

See the Privacy Policy for details.

Notice: This is a personal OAuth configuration. It is not an official Google service and is not an official service operated by the OpenClaw project.
